# Quick Start Guide

Get started with your Interactive Console Todo App in 2 minutes!

## 🚀 Launch the App

```bash
python3 main.py
```

## 📝 Your First Task (30 seconds)

1. **Welcome screen appears** → Press Enter
2. **Main menu appears** → Type `1` and press Enter
3. **"Task title:"** → Type `Buy groceries` and press Enter
4. **"Description:"** → Press Enter (skip)
5. **"Priority:"** → Type `1` (High) and press Enter
6. **"Tags:"** → Press Enter (skip)
7. **"Due date:"** → Press Enter (skip)
8. **Success!** → Press Enter to continue

✅ You just created your first task!

## 👀 View Your Tasks

1. **Main menu** → Type `2` and press Enter
2. **See your task:**
   ```
   #    Status   Title            Priority
   1    ⏳ Todo  Buy groceries    HIGH
   ```
3. Press Enter to continue

## ✓ Mark Task Complete

1. **Main menu** → Type `4` and press Enter
2. **See numbered tasks** → Type `1` (for task #1) and press Enter
3. **Task marked complete!** ✅
4. Press Enter to continue

## 🗑️ Delete a Task

1. **Main menu** → Type `5` and press Enter
2. **See numbered tasks** → Type `1` and press Enter
3. **Confirmation:** Type `yes` and press Enter
4. **Task deleted!**

## 🎯 That's It!

You now know how to:
- ✅ Add tasks
- ✅ View tasks
- ✅ Complete tasks
- ✅ Delete tasks

**Everything else works the same way:**
- All options visible on screen
- Select by number
- Follow the prompts
- No commands to memorize!

## 🔍 Explore More

- **Option 3:** Update task details
- **Option 6:** Search, filter, and sort tasks
  - Search by keyword
  - Filter by priority, status, or tag
  - Show overdue or upcoming tasks
  - Sort by date, priority, or title

## 💡 Pro Tips

- **Cancel anytime:** Type `0` when asked for task number
- **Skip optional fields:** Just press Enter
- **Safe deletions:** Must type 'yes' to confirm
- **Always visible:** Menu shows all options every time
